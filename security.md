## 🧭 Getting It Running The First Time

The failures at first launch are almost always environmental, not software.

**The sequence that works**

1. **Extract** the archive to a folder you control. A secondary drive is ideal.
2. **Never** run it from inside the compressed archive viewer.
3. **Right-click → Run as administrator.** The overlay needs to draw above the
   game window; without elevation it silently does nothing.
4. **Wait for the updater.** Launching modules while the updater is still writing
   is the second most common cause of a failed first run.
5. **Start with everything off**, then enable one module.

**The four first-run failures**

| **Symptom** | **Cause** | **Fix** |
| --- | --- | --- |
| Overlay never appears | not elevated | run as administrator |
| Loader closes instantly | ran from the archive | extract first |
| Settings not saved | folder is read-only | move out of a protected path |
| Integrity check fails | partial extraction | re-extract the whole archive |

**Antivirus**

Expect a detection. These loaders are flagged by heuristic engines because of how
they hook into a running process, not because of anything specific in the build.
Add the folder to exclusions before the first launch — doing it afterwards means
the file may already be quarantined.

**Verifying it took**

The menu should open on the configured hotkey with the game focused. If the hotkey
does nothing, the overlay is not attached — go back to step 3.
